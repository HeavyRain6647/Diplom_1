# Дипломный проект: Автоматизация тестирования Stellar Burgers

Финальный проект курса по автоматизации, включающий в себя юнит-тестирование логики, а также UI и API тесты сервиса заказа бургеров.

## 🛠 Технологии и инструменты
* **Язык:** Python 3.x
* **Тест-фреймворк:** Pytest
* **Библиотеки:** Selenium WebDriver (UI), Requests (API)
* **Покрытие кода:** Pytest-cov
* **Архитектура:** Page Object Model (POM)

## 📊 Часть 1: Юнит-тестирование (Unit Tests)
Автотесты для проверки внутренней логики программы (классы Bun, Burger, Ingredient, Database).
* **Результат:** Достигнуто 100% покрытие кода тестами.
* **Структура:** * `praktikum` — исходный код приложения.
    * `tests` — тесты, разделенные по классам (`bun_test.py`, `burger_test.py` и др.).

## 🌐 Часть 2: UI и API Автоматизация
Автоматизированные сценарии для веб-интерфейса и бэкенда сервиса.
* **UI:** Регистрация, авторизация, работа с конструктором и личным кабинетом (использован паттерн POM).
* **API:** Создание, изменение данных и удаление пользователя, работа с заказами.
